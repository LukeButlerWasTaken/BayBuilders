# Bay Builders (static Bootstrap version)

No install or build step.

1. Open this folder in VS Code.
2. Install the "Live Server" extension, right-click `index.html` → **Open with Live Server**.
   (Double-clicking `index.html` also works.)

Edit text and image URLs directly in `index.html`. Styles are in `css/style.css`,
behaviour in `js/main.js`. EmailJS keys for the contact form are at the top of `js/main.js`.
Bootstrap, Bootstrap Icons, EmailJS and the font are bundled in `vendor/` and work offline.
Photos and videos are still loaded from Cloudinary, so they need an internet connection.
